# Roads Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Garden boxes get roads (paths) between and around their areas — automatically or one per border — that cut back the areas in every season and year, and the area canvas gets its zoom and scrolling back.

**Architecture:** A new pure domain module `src/domain/roads/` (rectangle difference, borders, road placement, cut back). Roads live on `GardenBoxData.roads`; the `Planning` entity cuts its areas back and refuses edits onto roads; `optimizeSeason` treats roads as fixed pieces. Storage v7. `SeasonAreaCanvas` draws roads, + buttons and dialogs, inside the old scroll/zoom shell.

**Tech Stack:** React Native 0.81 + Expo 54, TypeScript strict, Zustand 5, Zod 3, i18next (Dutch), NativeWind, `node --test` (type stripping), Maestro.

**Spec:** `docs/superpowers/specs/2026-11-07-roads-design.md`

## Global Constraints

- Roads only on garden boxes (`type: 'gardenBox'`); pots and towers: no roads, no road UI.
- Road = `{ id, xCm, yCm, widthCm, lengthCm, locked? }` in the inner-area coordinate space of area pieces (top-left, cm).
- Road on a border between areas: centred on the border line, spans only the shared segment. On the box edge: inside the box against the edge. Clamped to the box; zero size after clamping → not added.
- Width 10–200 cm, integer, default 30 (or last used).
- New/widened roads cut back areas in **every season of every year** of the box, locked areas included; keep at most 3 largest remaining rectangles ≥ the plant's minimum side; nothing left → area removed (planting stays, unplaced, fixed seasons released as `removeArea` does) and that season `outdated`. Removing/narrowing a road never grows areas.
- Automatic roads: remove all unlocked roads; a road on every border **between two areas** of the shown season (carried areas included) not covered by a locked road; plus the ring (4 roads) when "ook rondom".
- Target percentages unchanged.
- Pan/zoom as the old `PlantPlacementCanvas` (git `aaa0528~1:src/components/organisms/PlantPlacementCanvas/PlantPlacementCanvas.tsx` lines ~719–1040): vertical ScrollView + nested horizontal ScrollView, scrolling only when the zoomed box exceeds the view, centred on zoom; buttons + / % / − bottom-left, 0.5×–3×, step 0.25; **also available in edit mode**.
- Domain, schemas, migrations, view models and their tests: relative `.ts` imports, no parameter properties/enums (node type stripping).
- All UI strings Dutch via `src/i18n/nl.json`; components presentational; BEM contract in `src/styles/planning/season.css`.
- File writes: Write/Edit; on EPERM or any I/O error stop and report. Preserve line endings. Stage explicitly (never `git add -A`; `.idea/misc.xml` and untracked root files stay out). Commit trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Branch `feature/roads`.
- Time discipline: wrap node runs in `timeout 180`.

## Review Focus

1. A road through the middle of an area in another season/year (not on its border) — area splits into ≤ 3 pieces or is removed; no zero-size or overlapping pieces. Test in Task 1 (cutBack) and Task 2 (Planning).
2. Borders of partially overlapping edges (area A 0–100 tall next to B 50–150) — + only on the 50–100 segment. Test in Task 1.
3. Automatic roads twice in a row — no duplicate roads, areas shrink only once more by the new unlocked roads (old unlocked ones removed first; space they freed stays free). Test in Task 3.
4. Re-optimizing after roads — no area overlaps a road. Test in Task 2.
5. Migration of v6 data and garbage `roads` values — no throw; invalid roads dropped; non-garden-box roads dropped. Test in Task 3.

### Task 1: Road geometry (pure domain)

**Files:**
- Modify: `src/types/component.types.ts` — add `RoadData { readonly id: string; readonly xCm: number; readonly yCm: number; readonly widthCm: number; readonly lengthCm: number; readonly locked?: boolean }`; `GardenBoxData.roads?: readonly RoadData[]`. Export via `src/types/index.ts`.
- Modify: `src/domain/planning/PlantFootprint.ts` — export `minimumAreaSideOf(traits: FootprintTraits): number` (move the private `minimumSideOf` from `AreaLayout.ts`, which then imports it).
- Create: `src/domain/roads/Rectangles.ts` (+ test) — `subtractRectangle(piece: AreaPiece, cut: AreaPiece): AreaPiece[]` (≤ 4 disjoint rectangles: band split top/bottom full width, left/right middle band), `subtractAll(piece, cuts): AreaPiece[]`, `overlaps(a, b): boolean` (positive overlap area).
- Create: `src/domain/roads/Borders.ts` (+ test) — `bordersOf(areas: readonly Pick<AreaData,'id'|'pieces'>[], box: { widthCm; lengthCm }, roads: readonly AreaPiece[]): Border[]`.
- Create: `src/domain/roads/RoadPlacement.ts` (+ test) — `roadOnBorder(border, widthCm, box): AreaPiece | null`, `ringRoads(widthCm, box): AreaPiece[]`, `automaticRoads(input): AreaPiece[]`, `withWidth(road: RoadData, widthCm, box): RoadData`.
- Create: `src/domain/roads/CutBack.ts` (+ test) — `cutBack(pieces: readonly AreaPiece[], roads: readonly AreaPiece[], minSideCm: number): AreaPiece[] | null` (null = nothing usable; returns the same array instance when no road overlaps).
- Create: `src/domain/roads/index.ts`.

**Interfaces:**

```ts
export interface Border {
  readonly orientation: 'vertical' | 'horizontal'; // vertical = the line x = constant
  readonly lineCm: number;                         // x for vertical, y for horizontal
  readonly fromCm: number;                         // start of the segment along the line
  readonly toCm: number;                           // end, toCm > fromCm
  readonly kind: 'between' | 'edge';               // two areas, or area on the box edge
  /** edge only: which side of the line the box interior lies ('after' = larger coordinates) */
  readonly inside?: 'before' | 'after';
}
export interface AutomaticRoadsInput {
  readonly areas: readonly Pick<AreaData, 'id' | 'pieces'>[];
  readonly box: { readonly widthCm: number; readonly lengthCm: number };
  readonly widthCm: number;
  readonly withRing: boolean;
  readonly lockedRoads: readonly AreaPiece[];
}
```

`withWidth`: a road whose rectangle touches a box edge along its long side keeps that side on the edge; otherwise it stays centred on its centre line. Road orientation = its short side is the width (`widthCm <= lengthCm` → vertical road, short side x).

**Tests (write first):**
- Rectangles: {0,0,100,100} minus {40,0,20,100} → 2 pieces (0–40, 60–100), total 8000; minus middle {40,40,20,20} → 4 pieces total 9600, disjoint; minus non-overlapping → same piece; minus covering → [].
- Borders: A {0,0,50,100} and B {50,0,50,100} in box 100×100 → one `between` vertical border x=50, 0–100, plus `edge` borders; A {0,0,50,100}, B {50,50,50,100} in box 100×150 → between segment 50–100 only; two pieces of the same area touching → no border; a border fully covered by a road → left out; deterministic order (input reversed → deepEqual).
- RoadPlacement: border x=50, 0–100, width 30 → {35,0,30,100}; edge border x=0 inside 'after' width 30 → {0,0,30,100}; road clamped at box edge; ringRoads(20, 100×80) → 4 roads, top/bottom full width, sides between them, no overlaps, union = ring; automaticRoads on two side-by-side areas with ring → 5 roads; with a locked road covering the shared border → only the ring; `withWidth` centred road 30→50 keeps centre; edge road keeps the edge.
- CutBack: piece {0,0,50,100} with road {35,0,30,100} → [{0,0,35,100}]; road through the middle of {0,0,100,100} horizontally, minSide 20 → 2 pieces; leftover thinner than minSide dropped; more than 3 leftovers → 3 largest; nothing ≥ minSide → null; no overlap → same instance.

### Task 2: Planning and optimizer respect roads

**Files:** Modify `src/domain/planning/Planning.ts` (+ test), `src/domain/planning/SeasonOptimization.ts` (+ test), `src/domain/planning/index.ts`.

**Interfaces:**
- `Planning.cutBackByRoads(roads: readonly AreaPiece[], minSideOf: (plantId: string) => number): Planning` — every area of every season through `cutBack`; null → area removed exactly as `removeArea` does (planting unplaced, fixed seasons released, later seasons outdated) and that season `outdated`; areas that only shrank keep status. Returns `this` when nothing changes. Unknown plants: minSide 1.
- `moveArea(season, areaId, dx, dy, bounds, roads: readonly AreaPiece[] = [])` and `resizeArea(..., bounds, roads = [])` — refused when a changed piece overlaps a road (extend `fitsBeside`).
- `SeasonOptimizationInput.roads?: readonly AreaPiece[]` — added to `fixed` on layer 0.

**Tests:** cut back an area in spring and a carried area in summer by one road → both shrink, statuses unchanged; road covering a whole area → area gone, planting unplaced, season outdated; locked area also shrinks and stays locked; moveArea onto a road refused, beside it accepted; resizeArea into a road refused; optimizeSeason with a road across the middle of 200×200 → no area overlaps the road (Review Focus 4).

### Task 3: Storage v7 and store actions

**Interfaces (componentStore):**

- `moveArea` / `resizeArea` pass the box's roads; `optimizeSeason` passes `roads`.
